# Changelog

## 0.1.0

- 首次移植 Pi 扩展 `pi-cardex`：`/cardex` 记录问答，`/cardex end` 由模型拆成知识卡片、维护三级知识树并生成离线 HTML 图谱。
- 不再拦截输入：消息不会被吞回编辑框，归档时从会话日志整段提取。
- `/cardex 问题` 开始记录并发送问题；已有知识目录时可能调用模型检索，`/cardex end` 调用模型整理归档。
- 整理成功后、写入归档前冻结问答快照；后续重试复用快照，已有 recordId 时直接恢复。
- 命令冲突改为报错提示 `/cardex --` 转义，不再把多余参数静默当成问题。
- 复用 `~/journal/cardex` 的 v2 索引、卡片、讨论文件与离线图谱，读写格式与旧版一致。
