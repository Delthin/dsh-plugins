# 全局置顶

[English](<README.en.md>)

把 DSH 已渲染的置顶会话行集中提到工作区上方。使用同一个原生节点，继承当前主题（包括 Claude Style）的字体、缩进、运行状态、悬停和操作菜单，不另画一套会话列表。

## 使用

- 继续使用 DSH 原有的“置顶／取消置顶”，无需重新收藏。
- 打开对话、选中态、标题展开、悬停卡片、状态点和快捷操作都由原生会话行处理；插件不额外添加悬停说明。
- 同一条原生行只显示一次，提升后不在原位置重复绘制。
- 原生视图重建时重新绑定当前节点；停用插件会恢复行的位置，置顶状态保留。
- 只提升当前原生视图已渲染的置顶行。折叠分组或搜索隐藏的行会随原生视图显隐；插件不强制展开工作区或切换视图。

## 设置

打开 **插件 → 全局置顶**，选择 **显示位置** 后保存：

- **工作区列表上方**：独立置顶区，列表较长时单独滚动。
- **工作区列表内**：集中显示一组置顶行，与原生列表一起滚动。

默认在工作区上方。设置由 DSH 保存，接受的修改即时生效并同步到其他已连接页面。行密度跟随 DSH 和当前主题；旧版密度配置仍可读取，但不再覆盖原生样式。

## 安装

当前为 `0.1.0` 私有开发版。从仓库根目录检查并生成本地安装包：

```bash
npm run check -- --package=global-pins
npm run check:pack -- --package=global-pins
```

安装包输出到仓库缓存目录 `.cache/packs/`。在目标 DSH 环境中安装生成的 `.tgz`，按宿主插件接入流程加载包内 [cordis.patch.yml](<cordis.patch.yml>)。服务重启需单独确认时间窗口。

## 兼容与安全

最低宿主声明为 `DSH >=0.2.2-rc.1`，Node.js 要求为 `>=22.19.0`。当前适配对象是 DSH Web `0.2.2-rc.1`，已对照 Claude Style 的日期视图验收。

该版本没有公开的原生行渲染接口。插件通过 `shell.overlay` 接入，在 `[data-slot="sidebar.workspaces"]` 前方或其原生滚动列表内设置置顶区，以 CSS 布局提升现有 `[data-row-key="session:…"]` 行，保留 React 管理的原父节点，不搬走或克隆会话节点。宿主升级或更换侧栏后需验证这些 DOM 适配点。

插件读取原生置顶 ID 和已展示行的布局，不读取对话正文、不复制状态、不另建置顶存储。打开、取消置顶及其他会话操作仍由原生行和宿主权限检查处理。显示位置通过 DSH 配置保存。
