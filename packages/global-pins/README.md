# 全局置顶

[English](<README.en.md>)

把 DSH 已置顶的对话集中显示在左侧所有工作区上方。继续使用原有的“置顶／取消置顶”，无需重新收藏。

## 使用

- 置顶区按宿主置顶列表顺序显示对话标题和所属工作区，不跟随工作区内的手动或最近更新排序；工作区折叠后仍可打开。
- 点击标题打开对话，点击行末的取消置顶按钮移除置顶。
- 原工作区列表完整保留，置顶对话在原位置仍可见。
- 无置顶对话或侧栏收起时不占空间；条目较多时置顶区单独滚动。归档、已删除及摘要尚不可用的会话不显示。

## 安装

当前为 `0.1.0` 私有开发版，尚未发布 npm 或插件市场。请从仓库根目录检查并生成本地安装包：

```bash
npm run check -- --package=global-pins
npm run check:pack -- --package=global-pins
```

安装包输出到仓库缓存目录 `.cache/packs/`。在目标 DSH 环境中安装生成的 `.tgz`，按宿主插件接入流程加载包内 [cordis.patch.yml](<cordis.patch.yml>)。首次加载如需重启服务，应先确认正在运行的任务和重启时间窗口。

无需额外配置。停用插件会移除全局置顶区，DSH 原有的置顶状态保留。

## 兼容与安全

最低宿主声明为 `DSH >=0.2.2-rc.1`，Node.js 要求为 `>=22.19.0`。当前适配对象是 DSH Web 的 `0.2.2-rc.1` 侧栏。

该版本没有工作区顶部的独立扩展插槽。插件通过 `shell.overlay` 注册，在 `[data-slot="sidebar.workspaces"]` 前插入自身容器，保留原生浏览器。这个 DOM 锚点属于版本相关适配点；宿主升级或替换侧栏后需重新验证。找不到锚点时不插入内容，不替换原生列表。

插件只读取会话列表摘要、工作区归属和原生置顶状态；打开及取消置顶走宿主接口及其权限检查。不读取对话正文，不新增服务端存储，也不复制置顶数据。

## 常见问题

**为什么原工作区内还显示相同对话？** 全局置顶区提供快捷入口，原生分组保留，避免改变搜索、排序与归档行为。

**启用后看不到置顶区？** 先确认侧栏已展开且至少有一条未归档、摘要已加载的置顶会话；如果修改过侧栏或升级宿主，请检查适配锚点。
